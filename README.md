## Projetos em destaque

### [ProfJa](https://github.com/joseaugusto10/profja-web)

Aplicação web para organizar a rotina de professores, com lançamento de aulas, histórico e agenda de compromissos.

- Interface responsiva, formulários validados e filtros de consulta.
- Agenda com compromissos recorrentes e integração HTTP documentada.
- **Tecnologias:** React, TypeScript, Vite, Tailwind CSS, TanStack Query, Zod e Mockoon.
- Testes automatizados com Vitest e instruções para execução local no repositório.

### [Visual Studio Purple Dark JA](https://github.com/joseaugusto10/visual-studio-purple-dark-ja)

Tema para o Visual Studio Code inspirado no Visual Studio, com editor escuro, detalhes roxos e realce de sintaxe.

- Identidade visual própria com as iniciais JA.
- Código-fonte e pacote VSIX disponíveis no repositório.
- Criado para compartilhar com a **.Net Brasil Community**.
